# 期后调整设计（关账后晚到记录）

## 问题约束

1. 复核通过即关账，已发布的权益（股份）与现金分录不得再被改写。
2. 关账后仍有登记/到账记录补来：塞进旧批次会改掉已发布数字；算进当期会在两期重复派发。
3. 每笔晚到记录必须且只能归属一个期间；同一笔重跑不能重复生效。
4. 复核页面要能同时看清原期间、调整期间与两期差异；旧批次原始依据保持可查。

## 核心原则：只追加，不改写（append-only adjustment）

旧批次（runs 表）在决策变为“通过”后即为**关账批次**，其 payload、证据 CSV、复核版本号全部冻结，任何新提交不得 UPDATE 它的行。
晚到记录一律进入一张新的调整单，以**调整分录**的形式落在当前开放期间，分录同时携带原期间与调整期间：

- `origin_period`：业务应属期间（按登记日/快照日判定，即旧批次期间）。
- `adjust_period`：分录实际生效期间（当前开放期间，默认“当期”）。
- 客户对账视图按 `adjust_period` 计一次现金/权益变动；报表追溯按 `origin_period` 能还原“业务本来属于哪期”。
- 因此一笔晚到记录在任何汇总口径里只被计一次——它只有一个生效期间，原期间只作标注、不重新入账。

## 期间状态机

```
开放(open) ──关账──▶ 已关账(closed) ──(不可回退)
```

- 调整单只能提交到 `open` 期间；目标期间已关账时返回 422（`PERIOD_CLOSED`），不允许落库。
- 关账动作只改期间表状态，不改任何已生成分录。
- 期后调整单自身有独立复核流：待复核 → 通过（生效）/ 退回（不生效，留痕）。调整单复核不触碰旧批次。

## 幂等：同一笔重跑不重复生效

每条晚到记录取稳定业务键
`idem_key = sha256(规则版本 | 来源批次 | 记录ID | 证券 | 快照日 | 行内容摘要)`。

- `adjustment_entries` 表对 `idem_key` 建 UNIQUE 约束，重复提交在数据库层去重，重跑返回既有分录且 `reused=true`，不产生第二笔。
- 同一来源文件整体也有 `source_sha256`，同文重复提交直接复用整单（沿用 runs 表既有做法）。
- 内容冲突（同业务键、金额/股数不同）不覆盖，隔离并给原因码 `CONFLICT`，由人工复核裁决。

## 差异计算口径

对每条晚到记录，先在旧批次冻结数据里定位同 `record + security` 的原始依据（持仓快照、已发布分红、行动版本），再用同一套 `domain.entitlement` / `allocate_cents` 规则复算：

| 场景 | 原期间数字 | 调整期间分录 |
|---|---|---|
| 漏报持仓（旧批次无此记录，如快照日晚于关账才到） | 0 | 新增股份 + 现金分红，类型 `新增派发` |
| 现金到账与已发布数不符 | 已发布应付 | 仅现金差额，类型 `现金补差`（可正可负），股份差为 0 |
| 行动版本修订引发的权益变化 | 旧版本结果 | 股份差 + 现金差，类型 `权益修订`（与 M7 修订回放同口径） |

每条分录输出：原期间、调整期间、原股份/新股份、股份差、原现金/调整现金、现金差、依据行号、来源文件 SHA、幂等键。
调整单汇总两期差异合计（股份差合计、现金差合计），页面按“原期间 → 调整期间”成对展示。

## 可追溯性

- 分录保存 `source_run_id`（旧批次）、`source_sha256`、`source_line`（原始行号），旧批次证据 CSV 仍可独立导出且内容不变。
- 调整单有自己的证据导出，含每条分录的幂等键与原始依据快照。
- 退回的调整单同样保留记录与原因，只是不生效。

## 落地结构（M8 期后调整）

| 组件 | 文件 | 职责 |
|---|---|---|
| 期间与调整单存储 | `app/adjust_store.py` | periods / adjustment_batches / adjustment_entries 表，状态机与幂等写入 |
| 晚到记录解析 | `app/modules/m8_adjustments/rules.py` | 解析、业务键、差异复算、冲突隔离 |
| 服务层 | `app/modules/m8_adjustments/service.py` | 组装调整单、汇总两期差异 |
| API | `app/modules/m8_adjustments/handler.py` + `main.py` 路由 | 提交/查询/复核/关账/证据导出 |
| 复核页面 | `templates/m8.html` | 原期间、调整期间、两期差异对照表 |
| 测试 | `tests/test_m8.py` | 关账冻结、唯一归属、幂等、冲突、差异口径、复核流 |
